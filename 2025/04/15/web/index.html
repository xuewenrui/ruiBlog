前端开发常用技术

🧱 一、布局相关

  1. display（布局模式）
    block：块级元素（独占一行）

inline：行内元素

inline-block：既能设置宽高又不换行

flex：弹性盒子（常用于布局）

grid：网格布局（高级）

  1. position（定位）
    static（默认）

relative（相对定位）

absolute（绝对定位）

fixed（固定在屏幕上）

sticky（粘性定位，适合吸顶效果）

  1. float（浮动，已较少用）
    left、right、none

  2. z-index（层级）
    控制元素的叠放顺序，数字越大越靠上

📏 二、尺寸与盒模型

  1. width / height / max-width / min-height 等
  2. margin（外边距） & padding（内边距）
    css
    复制
    编辑
    margin: 10px; /* 四个方向一样 /
    margin: 10px 20px; /     上下10px，左右20px */
  3. box-sizing
    content-box：默认，padding 不算进 width

border-box：推荐用，padding 和 border 都包含在 width 里

🎨 三、字体与文本样式
font-size：字体大小

font-weight：字体粗细（bold / 400 / 700）

color：字体颜色

text-align：对齐方式（left, center, right）

line-height：行高

letter-spacing：字间距

text-decoration：下划线等（underline, none）

🎨 四、背景与边框
background-color：背景色

background-image：背景图

background-size：背景图尺寸（cover, contain）

border：边框（如：1px solid #ccc）

border-radius：圆角（圆形元素用 50%）

box-shadow：阴影

🖱️ 五、交互样式

  1. 鼠标样式
    css
    复制
    编辑
    cursor: pointer; /* 像按钮一样的手型 */
  2. 过渡动画
    css
    复制
    编辑
    transition: all 0.3s ease;
  3. 伪类（常用于交互）
    css
    复制
    编辑
    a:hover { color: red; } /* 鼠标悬停 /
    input:focus { border: blue; } /     获得焦点时 /
    🧩 六、Flex 弹性布局（常用）
    css
    复制
    编辑
    display: flex;
    justify-content: center; /     横向居中 /
    align-items: center; /     纵向居中 /
    flex-direction: column; /     垂直排列 /
    gap: 10px; /     子元素间距 */
    📱 七、响应式相关
    @media 媒体查询（响应式设计）
    css
    复制
    编辑
    @media (max-width: 768px) {
    .box {
    display: block;
    }
    }
