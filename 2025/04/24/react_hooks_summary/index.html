React 常用 Hooks 详解

React Hooks 是 React 16.8 引入的一种机制，使我们可以在函数组件中使用状态和其他 React 特性。以下是一些常用 Hooks 的详细说明：

1. useState

作用：声明组件中的状态变量。
适用场景：计数器、表单值、开关状态等。

2. useEffect

作用：在组件生命周期内执行副作用操作。
适用场景：请求数据、事件监听、定时器等。

3. useContext

作用：访问 Context 中的共享值。
适用场景：跨组件传递数据，如主题、用户信息。

4. useRef

作用：访问 DOM 或保存一个可变引用值。
适用场景：保存定时器 ID、避免重复渲染。

5. useMemo

作用：缓存计算值，提高性能。
适用场景：性能敏感的复杂计算。

6. useCallback

作用：缓存函数引用，防止子组件重复渲染。
适用场景：将回调函数传给子组件时。

7. useReducer

作用：替代 useState 管理复杂状态。
适用场景：多个相关状态，或状态变更逻辑复杂。

8. useLayoutEffect

作用：同步执行副作用，优先于浏览器绘制。
适用场景：读取 DOM 尺寸或设置样式前。

9. useImperativeHandle

作用：自定义暴露给父组件的 ref 实例值。
适用场景：封装组件并暴露内部方法。

10. useId（React 18+）

作用：生成唯一 ID，用于无冲突关联表单元素。
适用场景：多个组件实例时避免 ID 冲突。

如需更多 Hooks 使用示例，请参考官方文档：React Hooks
